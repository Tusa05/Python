# Описание проекта

## Запустить тесты для формирования отчета.

python -m pytest 10_lesson --alluredir allure-results

### Эта команда:
python -m pytest: Запускает фреймворк Pytest.
10_lesson: Указывает Pytest, что нужно выполнить тесты только в этой папке.
--alluredir allure-results: Сохраняет результаты выполнения тестов в папку allure-results.

## Просмотреть сформированный отчет.

allure serve allure-results

### Эта команда:
Обработает необработанные данные из папки allure-results, содержащие информацию только о тестах из 10_lesson.
Сгенерирует HTML-отчёт.
Автоматически запустит локальный веб-сервер и откроет отчёт в браузере.
